
# ⭐ Pattern Generator and Number Analyzer

A beginner-friendly Python project that combines star pattern generation and number analysis to demonstrate the fundamentals of Python programming.

## 📌 Project Overview

The Pattern Generator and Number Analyzer is a menu-driven Python application developed to practice basic programming concepts. It allows users to generate star patterns, identify odd and even numbers within a given range, and calculate their sum.

The project focuses on understanding loops, control structures, and logical problem-solving through simple practical examples.

## ✨ Features

- **Pattern Generation:** Creates star patterns using nested loops.
- **Odd Number Analysis:** Displays all odd numbers within a given range.
- **Even Number Analysis:** Displays all even numbers within a given range.
- **Sum Calculation:** Calculates the sum of all numbers in the selected range.
- **Menu-Driven Interface:** Allows users to select different operations.

## 🛠️ Concepts Used

This project demonstrates the following Python concepts:

## ▶️ How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python pattern_generator.py
```
